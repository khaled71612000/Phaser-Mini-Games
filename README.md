## Overview

A collection of Phaser 3 mini-games demonstrating different mechanics: platforming, shooting, puzzle-solving, and score chasing.

Built with **Phaser 3** — browser-based 2D gameplay using HTML5 Canvas, scene management, sprites, arcade physics, and input handling.

## Getting Started

```bash
git clone https://github.com/khaled71612000/Phaser-Mini-Games.git
cd Phaser-Mini-Games
npx serve .
# or: python -m http.server 8000
# or: open index.html in browser
```

## Controls

| Input | Action |
|-------|--------|
| Arrow Keys / WASD | Move |
| Space | Jump / Fire |
